## 1. 게임 개요

**파크골프 코리아(가칭)**는 전국의 실제 파크골프장을 3D로 재현하고, 플레이어가 원하는 구장을 골라 라운딩하는 스크린 파크골프 게임이다. 골프존이 '전국 골프장 라운딩'으로 스크린골프 시장을 열었듯, 파크골프의 핵심 경험인 **"내가 다니는 구장, 가보고 싶은 구장"**을 디지털로 옮기는 것이 이 게임의 출발점이다.

| 항목 | 내용 |

| 장르 | 스포츠 시뮬레이션 (파크골프) |

이 게임은 전문 골프 시뮬레이터처럼 정밀한 스윙 분석을 추구하지 않는다. 파크골프 본연의 **쉬움·느긋함·동네 커뮤니티**를 살리되, 실제 구장 선택이라는 한 가지 축에서 깊이를 확보한다.

**아트 방향**: 실사 비율이 높은 **세미 리얼**로 확정한다. 구장·수목·하늘은 사진 기반 재질로 실사에 가깝게, 캐릭터는 실제 체형 비율에 얼굴 디테일만 약간 정리한 수준으로 그려 시니어 사용자가 '내 모습'으로 받아들일 수 있게 한다. 과장된 비율의 캐주얼 캐릭터는 쓰지 않는다.

## 2. 핵심 콘셉트: 전국 파크골프장 선택 구조

게임의 중심 화면은 **대한민국 지도**다. 플레이어는 지도에서 시·도 → 시·군·구 → 구장 순으로 들어가 실제 구장을 고른다. 전국 파크골프장은 2025년 기준 약 400곳 이상이며(대한파크골프협회·지자체 등록 기준, 정확한 수치는 개발 착수 시 재확인), 한 번에 전부 만들 수 없으므로 **3단계 재현 등급**으로 콘텐츠를 운영한다.

| 등급 | 명칭 | 재현 방식 | 제작 비용 | 목표 수량(출시 시) |
| --- | --- | --- | --- | --- |
| S | 시그니처 구장 | 드론 사진측량 + 현장 답사, 홀별 실제 지형·수목·시설물 1:1 재현 | 구장당 4~6주 | 10곳 (부산 삼락·강서, 서울 한강, 경주, 대구, 광주, 춘천, 제주 등 지역 대표 구장) |
| A | 표준 재현 구장 | 공공 항공사진·지형 DEM·구장 배치도 기반 홀 레이아웃 재현, 공용 에셋 사용 | 구장당 1주 | 60곳 |
| B | 레이아웃 구장 | 홀 수·거리·파 정보만 반영한 절차적 생성, 지역 테마 배경 | 구장당 1일 미만 | 나머지 전 구장 (데이터 확보분) |

**파일럿 S등급: 경주 동궁과 월지 가상 구장**

첫 S등급은 실제 구장이 아니라 **경주 동궁과 월지(안압지) 일대를 배경으로 한 가상의 파크골프장**으로 만든다. 실제 구장 데이터의 사용 권리 협의 없이 재현 품질 기준·제작 파이프라인·모바일 성능 목표를 먼저 확정할 수 있고, 월지의 연못·누각·야간 조명이 게임의 대표 비주얼이 된다.

| 항목 | 설계 |
| --- | --- |
| 명칭(가칭) | 경주 월지 파크골프장 |
| 배경 | 동궁과 월지의 연못·임해전지 누각·주변 소나무숲을 원경으로 두고, 그 사이 평지에 9홀 2코스(A·B) 배치. 문화재 구역 내부에는 홀을 두지 않고 시각적 배경으로만 사용 |
| 홀 구성 | 코스당 파33, 파3 4홀·파4 4홀·파5 1홀, 40~95m. 연못을 따라 도는 워터홀 2개, 누각을 정면에 둔 시그니처 파5 1개 |
| 시간대 | 주간·석양·야간(월지 야경 조명) 3종. 야간은 라운드 보상으로 해금 |
| 제작 자료 | 공개 항공사진·DEM, 현장 사진 촬영, 누각·석축은 공용 한옥 에셋을 월지 사진 기준으로 조정 |
| 역할 | 전국 투어 캠페인의 시작 구장, 시즌 챔피언십 1회 대회 구장, 스토어 첫 화면 배경 |

이후 S등급은 실제 구장(부산 삼락·강서, 서울 한강 등)으로 확장하되, 지자체 협약이 늦어지는 지역은 같은 방식으로 지역 명소를 배경으로 한 가상 구장을 먼저 두고 실제 구장으로 교체한다.

**차별화 포인트**

1. **내 홈 구장**: 플레이어가 자주 가는 구장을 홈으로 지정하면 해당 구장의 리더보드·동호회·월례회 기능이 활성화된다. 오프라인 동호회를 그대로 온라인으로 옮긴다.
2. **구장 스탬프 투어**: 전국 구장을 라운딩할 때마다 스탬프를 모으고, 권역(영남·호남·수도권·강원·충청·제주)을 완주하면 보상을 준다. 실제 '파크골프 성지순례' 문화를 게임화한다.
3. **계절·날씨 동기화**: 실제 구장의 현재 계절과 기상청 날씨를 반영해 잔디색·낙엽·바람이 바뀐다. 겨울에 폐장하는 구장도 게임에서는 사계절 플레이 가능하다.
4. **등급 승격 투표**: B·A 등급 구장 중 플레이 수와 플레이어 요청이 많은 곳을 S등급으로 승격 제작한다. 커뮤니티가 콘텐츠 로드맵을 정한다.
5. **지자체 연계**: 구장 소개 페이지에 실제 위치·운영시간·이용료·주변 관광지를 넣어 지역 홍보 채널로 활용한다. 지자체와의 제작비 분담 모델로 S등급 확장 재원을 확보한다.

## 3. 코어 게임플레이

파크골프는 클럽 1개·공 1개·9홀 단위가 규칙이므로 샷 시스템은 골프보다 단순하되, **거리 조절과 경사 읽기**에 재미의 깊이를 둔다.

**3.1 샷 메커닉 (플랫폼별 입력)**

| 플랫폼 | 입력 방식 | 조작 흐름 | 우선순위 |
| --- | --- | --- | --- |
| 모바일 | 세로 화면, 한 손 터치 | ① 타깃점 지정 → ② 팔 높이(백스윙) 지정 → ③ 손목 꺾기 여부 결정 → 조준창 바늘로 훅·슬라이스·정확도 판정 | 1차 |
| PC | 마우스 또는 패드 | 같은 3단계를 클릭·드래그로 수행, 조준창 바늘은 키 입력으로 정지 | 2차 |
| VR | 컨트롤러 스윙 | 실제 스윙 모션 추적, 손목 꺾기는 컨트롤러 회전으로 감지 | 3차 |
| 키오스크 | 실제 클럽 + 광학/레이더 센서 | 실제 스윙 → 센서가 헤드 스피드·타구 각도·좌우 방향 측정 → 궤적 생성 | 최종(보류) |

샷 종류는 파크골프 실제 기술을 반영한다: **풀샷**(티샷·세컨샷), **런닝 어프로치**(그린 주변 굴리기), **퍼팅 스트로크**. 클럽은 하나지만 스탠스와 타점으로 세 가지 궤적을 구분한다.

**모바일 샷 조작 상세 (1차 플랫폼)**

샷은 **타깃점 → 팔 높이 → 손목 꺾기** 세 가지 결정으로 이루어지고, 결과의 좌우 편차(훅·슬라이스)와 정확도는 마지막에 움직이는 **조준창 바늘**을 멈추는 타이밍으로 정해진다. 실제 파크골프 스윙에서 거리는 백스윙 높이로, 방향은 손목과 임팩트로 결정된다는 점을 그대로 옮긴 구조다.

| 단계 | 조작 | 화면 반응 | 판정 |
| --- | --- | --- | --- |
| 1. 타깃점 지정 | 상단 코스 뷰에서 떨어뜨리고 싶은 지점을 탭(또는 드래그). 기본값은 홀컵 방향 안전 지점 | 타깃점에 깃발 마커, 공에서 타깃까지 직선 거리(m)와 고저차 표시, 경사·바람 보조선(난이도별) | 좌우 ±40°, 거리는 클럽 최대 비거리 이내 |
| 2. 팔 높이 지정 | 하단 캐릭터 측면 실루엣에서 팔(클럽)을 위로 드래그해 백스윙 높이를 정함. 손을 떼면 높이 고정 | 팔 각도에 따라 예상 비거리(m)가 타깃 거리와 나란히 표시. 허리·어깨·머리 위 3단 눈금, 타깃 거리와 일치하는 높이에 햅틱 틱 | 백스윙 각도 0~180° → 비거리 0~최대. 런닝 어프로치·퍼팅은 눈금이 1/4 스케일로 바뀜 |
| 3. 손목 꺾기 결정 | 토글 버튼: '손목 고정' / '손목 꺾기' | 꺾기 선택 시 실루엣 손목이 코킹되고 예상 비거리 +10~15%, 대신 조준창 바늘 속도 1.5배 | 고정: 비거리 그대로, 바늘 느림(안정) / 꺾기: 비거리 증가, 바늘 빠름(위험) |
| 4. 조준창 바늘 | 손목 결정 직후 조준창(가로 게이지)이 열리고 바늘이 좌→우→좌 왕복. 화면 아무 곳이나 탭해 바늘을 멈춤 | 중앙 '정확' 구간(초록), 좌측 '훅' 구간(주황→빨강), 우측 '슬라이스' 구간(주황→빨강). 바늘 위치에 따라 궤적 미리보기가 실시간으로 휘어짐 | 중앙 ±8%: 정확(타깃점 ±1m) / ±8~25%: 약한 훅·슬라이스(2~6° 휨, 비거리 −5%) / ±25% 이상: 강한 훅·슬라이스(7~12° 휨, 비거리 −12%) |
| 5. 스윙·비행 | 자동 | 캐릭터 스윙 → 공 뒤 3인칭 추적 → 낙하 전 탑뷰 → 정지 후 다음 샷 시점 | 전체 3~5초, 더블탭 스킵. 결과 라벨(굿샷·훅·슬라이스·쇼트·오버) 1초 표시 |

- 조준창 바늘 속도: 초보 1.0초/왕복, 일반 0.7초, 프로 0.5초. 손목 꺾기 선택 시 각각 1.5배. 바람이 강하면 '정확' 구간이 바람 반대쪽으로 살짝 밀려 표시된다(바람 보정 유도).
- 훅·슬라이스는 벌칙이 아니라 기술이다. 도그레그 홀이나 나무 뒤 타깃은 의도적으로 바늘을 훅·슬라이스 구간에 멈춰 돌려 넣는 것이 정답이며, 궤적 미리보기가 그 가능성을 보여준다.
- 샷 종류 전환: 1단계 타깃점이 그린 안이면 자동으로 퍼팅 모드(손목 꺾기 토글 숨김, 바늘 구간이 '좌/정확/우' 3구간으로 단순화). 그린 주변 10m 이내는 런닝 어프로치 제안.
- 되돌리기: 바늘이 열리기 전까지는 각 단계를 뒤로 갈 수 있다(화면 하단 '이전' 버튼). 바늘이 열리면 되돌릴 수 없다.
- 세로 화면 고정, 엄지 하나로 전 과정이 끝나야 한다. 1~3단계에는 시간 제한이 없고, 크루 게임에서만 샷 전체 30초 제한을 둔다.
- 햅틱: 팔 높이가 타깃 거리와 일치할 때 1회, 바늘이 정확 구간을 지날 때마다 약한 틱, 멈춘 결과가 정확이면 짧은 진동 2회.

**3.2 공 물리 모델**

- 공 규격: 직경 6cm, 무게 80~95g(실제 파크골프 공 규격)으로 골프공보다 느리고 낮게 날아간다. 탄도 계산은 공기저항 계수를 골프공의 약 2배로 설정해 비거리 30~80m 범위를 재현한다.
- 지면 물리: 페어웨이·러프·그린·벙커·OB 5종 표면별 마찰·반발 계수. 파크골프는 **런(구름)**이 비거리의 40~60%를 차지하므로 지면 경사와 굴림 시뮬레이션이 핵심이다.
- 바람: 구장별 실제 풍향 통계(기상청)를 기본값으로, 세기에 따라 탄도 보정. 초보 모드에서는 바람 영향 50% 감소.
- 경사 시각화: 그린과 어프로치 구간에 경사 그리드(골프존 스타일 흐름선)를 표시한다. 난이도에 따라 표시 범위를 줄인다.

**3.3 규칙 구현 (대한파크골프협회 경기규칙 기준)**

| 규칙 | 게임 내 처리 |
| --- | --- |
| 홀 구성 | 9홀 1코스, 파3·파4·파5, 코스 합계 파33, 홀 거리 40~100m |
| OB | 1벌타 후 OB 지점 인근 2클럽 이내 드롭(자동 배치) |
| 홀컵 | 직경 20~21cm. 홀인 판정은 공 전체가 컵 안으로 들어가야 함 |
| 최대 타수 | 홀당 파의 3배 초과 시 자동 홀아웃(더블파 룰 옵션) |
| 티샷 순서 | 전 홀 성적 순(오너 제도), 멀티플레이 시 적용 |
| 스코어 | 스트로크 플레이 기본, 동호회 모드에서 신페리오·핸디캡 적용 |

**3.4 난이도 설계**

초보(바람·경사 보조선 전부 표시, 파워 자동 추천) → 일반(보조선 부분 표시) → 프로(보조선 없음, 실제 거리 감각) → 리얼(키오스크 센서값 100% 반영) 4단계.

## 4. 전국 파크골프장 콘텐츠 시스템

구장은 게임의 핵심 콘텐츠이자 반복 제작 대상이므로, **데이터 → 제작 → 검수 → 배포**가 하나의 공장처럼 돌아야 한다.

**4.1 구장 데이터 모델**

| 레벨 | 엔티티 | 주요 필드 |
| --- | --- | --- |
| 1 | 권역(Region) | 권역명, 포함 시·도 목록, 스탬프 투어 보상 |
| 2 | 구장(Course) | 구장 ID, 명칭, 주소·좌표, 운영 주체(지자체·협회), 코스 수, 총 홀 수, 재현 등급(S/A/B), 개장 연도, 이용료, 실제 운영시간, 썸네일, 대표 풍향 |
| 3 | 코스(Layout) | 코스명(A·B·C·D), 9홀 구성, 코스 합계 파, 총 길이(m), 난이도 지수 |
| 4 | 홀(Hole) | 홀 번호, 파, 거리(m), 티 좌표, 홀컵 좌표, 그린 폴리곤, OB 폴리곤, 벙커·해저드 폴리곤, 지형 DEM 타일 참조, 추천 공략 라인 |
| 5 | 오브젝트(Prop) | 수목·벤치·안내판·펜스 등 공용 에셋 ID + 좌표·회전·스케일 |

데이터 수집 경로는 ① 대한파크골프협회·지자체 공개 구장 목록(명칭·주소·홀 수) ② 국토지리정보원 항공사진·수치지형도(DEM) ③ 구장별 안내판·홈페이지 코스 배치도 ④ 현장 드론 촬영(S등급)이다. 구장 ID는 협회 등록 번호를 기준으로 하되 없으면 `지역코드-일련번호`로 부여한다.

**4.2 제작 파이프라인**

&#91;embedded content: 구장 콘텐츠 제작 파이프라인 · 수집부터 배포까지 6단계, 등급별 3갈래\]

등급 판정 후 세 갈래로 나뉘어 제작되지만, UE5 빌드 단계부터는 같은 데이터 포맷과 QA 체크리스트를 거친다. QA에는 해당 구장을 실제로 다니는 동호회원 검수를 포함해 "내 구장이 맞다"는 체감을 확인한다.

**4.3 B등급 절차적 생성 규칙**

- 입력: 홀별 파·거리·개략 방향(배치도에서 추출), 구장 지형 유형(하천 둔치·공원·산지·매립지)
- 지형 유형별 템플릿 4종에 홀 레이아웃을 자동 배치하고, 페어웨이 폭 8~15m·그린 직경 8~12m 범위에서 난수 시드(구장 ID 기반)로 변형해 매번 같은 구장이 생성되도록 고정한다.
- 생성 결과는 A등급 제작의 초안으로 재사용된다.

## 5. 게임 모드와 진행 구조

모든 모드는 **구장 선택 → 코스 선택 → 라운딩 → 스코어카드**라는 동일한 뼈대를 공유하고, 누구와 어떻게 치는지만 달라진다.

| 모드 | 인원 | 설명 | 세션 길이 | 출시 단계 |
| --- | --- | --- | --- | --- |
| 자유 라운딩 | 1명 | 원하는 구장을 골라 9·18·36홀 플레이. 로그인 없이 가능 | 9홀 10분 | 1차 |
| 크루 게임 | 2~4명 | 친구·크루원과 실시간 동반 라운딩. 같은 홀을 순서대로 샷, 대기 중 응원 이모티콘. 10절 상세 | 9홀 15분 | 1차 |
| 모임(비공개 방) | 2~40명 | 친구들끼리만 입장하는 초대코드 방. 기간·구장·코스를 정해 비동기 라운딩, 방 안에서만 랭킹 공개. 10절 상세 | 1일~1주 | 1차 |
| 전국 투어(싱글 캠페인) | 1명 | 권역별 구장을 순서대로 돌며 스탬프 수집. 구장마다 목표 타수 미션 | 구장당 10분 | 1차 |
| 정기 대회 | 무제한 | 주간·월간·시즌 단위 비동기 대회. 12절 상세 | 대회별 상이 | 1차(주간) · 2차(시즌) |
| 챌린지(일일 미션) | 1명 | 매일 바뀌는 구장+조건(강풍·러프 그린 등)에서 1홀 기록 경쟁 | 3분 | 1차 |
| 연습장 | 1명 | 거리별 어프로치·퍼팅 드릴, 경사 읽기 훈련 | 자유 | 1차 |
| 스크린 라운딩(키오스크) | 1~4명 | 실물 클럽·센서 입력, 매장 과금 | 9홀 15분 | 최종(보류) |

**라운딩 진행 루프**

1. 티 그라운드 입장: 홀 정보(파·거리), 바람, 추천 라인 표시(난이도별)
2. 샷 → 공 궤적 카메라 추적 → 낙하 지점 도착
3. 라이 판정(페어웨이·러프·벙커·OB) 및 다음 샷 준비
4. 홀아웃 → 홀 결과(파·버디 연출, 타수) → 스코어카드 갱신
5. 9홀 종료 → 코스 결과(총타수, 베스트 샷 리플레이, 스탬프·경험치 획득)
6. 계속 라운딩(다음 코스) 또는 종료

**관전·리플레이**: 홀아웃마다 베스트 샷을 자동 저장하고, 결과 화면에서 공유 영상(세로 15초)을 생성한다. 동호회 단톡방 공유를 전제로 한 바이럴 장치다.

## 6. 플레이어 성장·메타 시스템

주 타깃이 시니어층이므로 성장은 **실력이 아니라 기록과 발자취**를 쌓는 방향으로 설계한다. 스탯 인플레이션으로 샷 결과가 바뀌는 구조는 공정성 시비와 복잡도를 낳으므로 피한다.

| 시스템 | 내용 | 효과 범위 | 상세 |
| --- | --- | --- | --- |
| 핸디캡 | 최근 20라운드 평균으로 자동 산출(협회 방식 준용). 크루·모임·대회의 네트 스코어에 사용 | 순위 계산에만 영향 | 11절 |
| 구장 스탬프 | 구장별 첫 라운딩·파 이내·언더파 3단계 스탬프. 권역 완주 시 칭호·의상 | 수집·과시 | 14절 |
| 기록·전적 | 모든 라운드가 날짜·구장·동반자와 함께 영구 저장. 개인 통계·베스트 샷 리플레이 | 기록 | 11절 |
| 캐릭터·아이템 | 외모·의상·신발 슬롯, 수집 등급, 세트 완성 시 승급. 샷 결과에는 영향 없음 | 외형·수집 | 14절 |
| 상점 | 인게임 아이템 + 실물 파크골프 공·클럽 커머스 | 과금 | 13절 |
| 정기 대회 | 주간·월간·시즌 대회, 결과가 전적에 남음 | 커뮤니티 경쟁 | 12절 |
| 시즌패스 | 시즌(3개월)마다 신규 S등급 구장 1~2곳, 시즌 한정 의상·신발, 스탬프 보너스 | 과금·리텐션 | 13절 |

**동호회(클럽) 시스템**

- 홈 구장을 같이 쓰는 플레이어끼리 클럽을 만든다(최대 40명). 클럽 공지, 월례회 일정, 합산 랭킹, 단체 스탬프 투어 미션을 제공한다.
- 실제 오프라인 동호회 임원이 클럽장이 되도록 '동호회 인증' 절차(협회 등록증 사진 검수)를 둔다. 인증 클럽은 구장 소개 페이지에 노출된다.

**시니어 접근성 원칙**

- 기본 글자 크기 18pt 이상, 버튼 최소 60px, 2단계 이내 메뉴 깊이
- 모든 안내는 음성 안내 병행(TTS), 키오스크에서는 터치 대신 실물 버튼 3개(샷·메뉴·확인)로도 전 기능 조작 가능
- 온라인 기능은 선택사항이며, 로그인 없이도 자유 라운딩 전 구장 플레이 가능

## 7. 화면 흐름 및 UI 구조

화면은 **전국 지도 허브 하나와 그 아래로 내려가는 라운딩 경로**로 단순화한다. 시니어 사용자가 어디에 있든 "지도로" 버튼 한 번으로 허브로 돌아온다.

&#91;embedded content: 화면 흐름 · 메인 허브 1개, 라운딩 경로 5단계\]

라운딩 경로는 지도 → 구장 상세 → 설정 → 라운딩 → 결과의 한 줄이며, 결과 화면에서 같은 구장 재도전·다른 구장 선택·종료를 고른다.

**주요 화면 상세**

| 화면 | 핵심 UI 요소 |
| --- | --- |
| 전국 지도 | 시·도 단위 지도(터치 확대), 지역별 구장 수 배지, 검색창(구장명·지역), 필터(S/A/B 등급·홀 수·내 스탬프 미보유), '내 홈 구장' 바로가기, 최근 플레이 구장 3개 |
| 구장 상세 | 구장 항공 뷰 회전 영상, 코스별 홀 맵과 파·거리 표, 내 베스트 스코어, 구장 리더보드, 실제 구장 정보(위치·운영시간·이용료·전화), 스탬프 현황 |
| 설정 | 코스(A/B/C/D) 선택, 홀 수(9/18/36), 모드, 참가 인원·이름 입력, 난이도, 날씨 동기화 온/오프 |
| 라운딩 HUD | 홀 번호·파·남은 거리(큰 글씨), 바람 표시, 현재 타수·합계, 순서 표시(멀티), 카메라 전환(티·홀컵·상공), 메뉴(스코어카드·설정·지도로) |
| 결과 | 코스 스코어카드(홀별 파 대비 색상), 베스트 샷 리플레이, 획득 스탬프·업적, 공유 영상 생성, 다음 행동 3버튼 |

**키오스크 UI 차이**: 터치 대신 실물 버튼 3개와 클럽 센서 입력으로 동일 흐름을 타며, 전국 지도 화면은 매장 위치 기반으로 '근처 구장'을 먼저 보여준다.

## 8. 기술 아키텍처

클라이언트는 **하나의 UE5 코드베이스**로 키오스크·PC·모바일·VR을 모두 다루고, 구장 콘텐츠는 게임 본체와 분리된 **코스 팩(팩 파일)**으로 CDN 배포해 클라이언트 업데이트 없이 구장을 추가한다.

&#91;embedded content: 기술 아키텍처 · 클라이언트–서버–데이터 3계층 + 콘텐츠 툴체인\]

**주요 기술 선택**

| 영역 | 선택 | 이유 |
| --- | --- | --- |
| 엔진 | Unreal Engine 5.5+ | 대규모 야외 지형(Landscape·World Partition), Nanite 수목, Lumen 자연광, PCG 프레임워크로 B등급 절차 생성 |
| 공 물리 | Chaos 대신 자체 결정론적 시뮬레이션 | 멀티플레이 동기화와 리플레이 재현을 위해 입력→결과가 플랫폼 무관하게 동일해야 함. 고정 틱(120Hz)으로 계산 |
| 코스 팩 | UE5 Pak 찭크 + 홀 데이터 JSON | 구장 1곳 = S등급 약 150~300MB, A등급 약 30~60MB, B등급은 생성 시드만(수 KB). 모바일은 온디맨드 다운로드 |
| 센서 어댑터 | 플러그인 인터페이스(헤드스피드·타구각·좌우각 3값) | 센서 제조사(광학·레이더)에 따라 교체 가능. 센서 없는 환경은 가상 입력 어댑터로 대체 |
| 서버 | Node.js(NestJS) 또는 Go, PostgreSQL+PostGIS, Redis | 구장 좌표·권역 검색에 공간 쿼리 필요. 비동기 대회는 배치 집계 |
| 실시간 매치 | 전용 서버 없는 릴레이 방식 (샷 입력값만 전송, 각 클라이언트가 결정론적 물리로 재현) | 터리쏼이게임이라 데디커티드 서버 물리가 불필요. 부정행위는 서버 사후 검증 |
| 날씨 | 기상청 단기예보 API → 구잠 좌표 기준 풍향·풍속·강수 | 시간당 1회 서버 캐시, 클라이언트는 API 서버만 호출 |
| 분석 | 자체 이벤트 로그(구장별 플레이 수·홀별 평균 타수·이탈 지점) | 등급 승격 투표와 홀 난이도 보정의 근거 |

**코스 팩 내부 구조**

```
COURSE_BS-0012/
  manifest.json        ← 구장 ID, 등급, 버전, 좌표, 코스 목록
  holes/*.json         ← 홀별 티·컵·그린·OB 폴리곤, 파, 거리
  terrain.pak          ← 지형 Landscape + 표면 레이어 (S/A만)
  props.pak            ← 구장 고유 에셋 (S만)
  thumbs/*.jpg         ← 지도·상세 화면용 썸네일
```

공용 에셋(수목·벤치·펜스·잔디 머티리얼)은 본체에 포함하고 코스 팩은 참조만 한다. 따라서 A·B등급 구장은 용량이 작고, B등급은 사실상 데이터 파일만 받으면 된다.

## 9. 개발 로드맵 및 마일스톤

출시까지 약 14개월, 이후 3개월 시즌제로 운영한다. **1차 출시는 모바일 단일 플랫폼**이며, 자유 라운딩·크루 게임·모임·기록실·주간 대회·상점·캐릭터 승급이 출시 범위다. PC와 VR은 라이브 단계에서 확장하고, 키오스크 센서 연동은 가장 마지막에 별도 사업으로 검토한다. 가장 이른 게이트는 실제 동호회원이 "내 구장이 맞다"고 느끼는지 확인하는 버티컬 슬라이스 플레이테스트다.

## 10. 크루·모임 시스템

크루는 **같이 치는 4명**, 모임은 **같이 겨루는 친구 집단**이다. 둘 다 친구 목록 위에서 돌아가며, 모르는 사람과 자동 매칭되는 기능은 1차에 넣지 않는다. 실제 파크골프가 4인 1조 동반 라운딩 문화이므로 그대로 옮긴다.

**10.1 친구 시스템 (공통 기반)**

| 항목 | 규칙 |
| --- | --- |
| 친구 추가 | 전화번호 연락처 동기화(선택), 카카오톡 초대 링크, 닉네임 검색, QR 코드(현장에서 만났을 때) |
| 친구 상한 | 500명 |
| 상태 표시 | 온라인·라운딩 중(구장명)·오프라인(마지막 접속 n일 전) |
| 차단·신고 | 차단 시 모든 방·대회 랭킹에서 서로 비노출 |

**10.2 크루 게임 (실시간, 2~4명)**

| 단계 | 규칙 |
| --- | --- |
| 방 만들기 | 방장이 구장·코스·홀 수(9/18)·난이도·바람 온/오프 설정 → 초대코드 6자리 생성(유효 30분) |
| 초대 | 친구 목록에서 직접 초대(푸시 알림) 또는 코드 공유(카카오톡 공유 버튼) |
| 입장 조건 | 코드 입력, 방장 수락 불필요. 4명 차면 자동 잠금 |
| 시작 | 전원 '준비' 후 방장이 시작. 2분 내 미준비자는 관전자로 전환 |
| 티샷 순서 | 1홀은 핸디캡 높은 순, 2홀부터 전 홀 성적 순(오너). 동점 시 이전 순서 유지 |
| 샷 제한 시간 | 1샷 30초. 초과 시 자동 샷(현재 조준·파워 70%). 3회 연속 초과 시 AI 대리 플레이 전환 |
| 대기 중 | 다른 플레이어의 샷을 자기 화면에서 관전. 응원 이모티콘 8종(굿샷·아쉽다·박수 등), 음성 채팅은 없음, 정형 문구 채팅 12종 |
| 동시 샷 옵션 | 방장이 켜면 티샷은 전원 동시 진행(대기 시간 단축), 그린 위 퍼팅만 순서대로 |
| 이탈 처리 | 연결 끊김 60초 내 복귀 시 이어서, 이후는 AI 대리 플레이 후 기록에 '중도 이탈' 표기 |
| 종료 | 홀별 스코어카드, 베스트 샷 투표(3표), 결과를 전적에 저장하고 단체 스코어카드 이미지 공유 |

**10.3 모임 (비공개 방, 비동기, 2~40명)**

| 항목 | 규칙 |
| --- | --- |
| 생성 | 모임명·설명·대표 이미지, 공개 범위는 항상 비공개(검색 불가). 초대로만 가입 |
| 역할 | 모임장 1명, 운영진 3명까지(일정 등록·멤버 관리), 일반 멤버 |
| 모임 라운딩 | 운영진이 '이번 주 라운딩'을 등록: 구장·코스·홀 수·기간(1~7일)·난이도 고정. 멤버는 기간 내 각자 1회(또는 n회 중 베스트) 플레이 |
| 랭킹 | 그로스·네트(핸디캡) 두 가지 동시 표시, 모임 안에서만 공개 |
| 월례회 | 매달 1회 운영진이 지정하는 공식 라운딩. 결과가 모임 명예의 전당에 누적 |
| 모임 스탬프 | 모임 전체가 같은 구장을 완주하면 단체 스탬프, 멤버 전원에게 보상 |
| 게시판 | 공지 1개 고정 + 라운딩별 댓글. 사진 첨부 가능(실제 현장 사진 공유 용도) |
| 모임 수 제한 | 1인당 가입 모임 5개, 운영 모임 2개 |
| 해산 | 모임장이 해산하면 기록은 각 멤버 전적에 남고 모임 페이지만 닫힘 |

실제 동호회 월례회를 그대로 옮기는 것이 목표이므로, 모임 라운딩은 **오프라인 라운딩 전후에 같은 구장을 게임에서 치는 흐름**(예습·복습)을 자연스럽게 유도하도록 구장 상세 페이지에서 '모임 라운딩 만들기' 버튼을 바로 노출한다.

## 11. 기록·전적 시스템

모든 라운드는 **지우지 않고 영구 저장**한다. 파크골프 동호인이 수첩에 스코어를 적는 습관을 디지털 기록실로 옮기는 것이 목적이며, 실제 오프라인 라운딩 기록도 수기로 입력해 같은 기록실에 쌓을 수 있다.

**11.1 저장 단위와 데이터 모델**

| 엔티티 | 필드 | 비고 |
| --- | --- | --- |
| Round(라운드) | 라운드 ID, 유저 ID, 구장 ID, 코스 ID, 홀 수, 모드(자유·크루·모임·대회·오프라인수기), 일시, 난이도, 바람 설정, 총타수, 파 대비(±), 동반자 ID 목록, 모임/대회 ID, 완주 여부 | 라운드 1건 = 9홀 또는 18홀 |
| HoleScore(홀 기록) | 라운드 ID, 홀 번호, 파, 타수, 퍼팅 수, 페어웨이 안착 여부, OB 횟수, 홀인원·이글·버디·파·보기·더블보기 이상 구분 | 홀마다 1건 |
| Shot(샷 로그) | 홀 기록 ID, 샷 순번, 샷 종류, 출발 좌표, 도착 좌표, 비거리(m), 라이(페어웨이·러프·벙커·그린), 파워·정확도 입력값 | 리플레이 재생용, 90일 후 압축 보관 |
| Highlight(하이라이트) | 라운드 ID, 샷 ID, 유형(홀인원·칩인·롱퍼팅·베스트샷 투표), 영상 생성 여부 | 영구 보관 |
| OfflineRound(수기 기록) | 구장 ID, 일시, 홀별 타수, 동반자 이름(텍스트), 메모, 현장 사진 | 게임 기록과 구분 표시, 핸디캡 계산에는 선택 반영 |

**11.2 기록실 화면 구성**

| 탭 | 내용 |
| --- | --- |
| 요약 | 총 라운드 수, 방문 구장 수(전국 n/400), 평균 타수, 핸디캡, 베스트 라운드, 홀인원 횟수, 이번 달 라운드 수 |
| 라운드 목록 | 최신순, 날짜·구장·모드·총타수·파 대비 한 줄. 필터: 구장·모드·기간·동반자. 각 라운드 → 홀별 스코어카드 + 샷 궤적 지도 |
| 통계 | 홀 유형별(파3·4·5) 평균, 퍼팅 평균, 페어웨이 안착률, OB율, 비거리 분포, 최근 20라운드 추세 그래프, 구장별 평균 타수 |
| 구장별 | 방문한 구장마다 베스트·평균·방문 횟수·스탬프 상태, 홀별 최고 기록 |
| 하이라이트 | 홀인원·칩인·롱퍼팅 리플레이 영상(세로 15초), 공유 버튼 |
| 동반자 | 같이 친 사람별 라운드 수·승패(크루 게임 기준) |

**11.3 스코어카드 공유**

- 라운드 종료 시 자동 생성: 구장 썸네일 + 날짜 + 홀별 타수 + 파 대비 색상(버디 이하 빨강, 보기 이상 파랑) + 동반자 캐릭터 4명 나란히.
- 세로 이미지(1080×1920)로 카카오톡·인스타그램 스토리에 바로 공유. 이미지 하단에 구장 실제 위치와 초대코드 QR(선택).
- 크루 게임은 4명 합산 단체 스코어카드, 모임 라운딩은 랭킹 포함 버전을 별도 생성.

**11.4 핸디캡 산출**

- 최근 20라운드 중 상위 8라운드의 '파 대비 평균'을 기준으로 계산하고, 18홀 환산한다. 9홀 라운드 2개를 묶어 1개로 본다.
- 수기 입력 오프라인 라운드는 유저가 '핸디캡 반영'을 켠 경우에만 포함한다.
- 난이도 '초보'에서 친 라운드는 핸디캡에서 제외하고 기록실에는 남긴다.

## 12. 정기 대회 운영 시스템

대회는 **매주·매달·매 시즌 정해진 요일에 자동으로 열리는 비동기 대회**다. 운영자가 매번 손대지 않아도 캘린더에 따라 생성·마감·시상이 돌아가야 하므로, 대회 템플릿과 스케줄러로 구성한다.

**12.1 대회 주기와 종류**

| 대회 | 주기 | 구장 | 참가 방식 | 순위 기준 | 보상 |
| --- | --- | --- | --- | --- | --- |
| 주간 오픈 | 매주 월 00:00 시작 ~ 일 23:59 마감 | 운영 선정 A·S등급 1곳, 매주 변경 | 무료, 기간 내 3회 시도 중 베스트 | 그로스 | 상위 10% 주간 배지, 1~3위 한정 의상 |
| 주간 핸디캡 | 주간 오픈과 동일 구장 | 동일 | 핸디캡 보유자(20라운드 이상) | 네트 | 입문자도 입상 가능한 보조 대회 |
| 권역 월례 | 매월 1일 ~ 말일 | 권역별 S등급 1곳(영남·호남·수도권·강원·충청·제주) | 무료, 5회 시도 중 베스트 | 그로스·네트 2부 | 권역 챔피언 칭호, 구장 상세 페이지에 명예 게시 |
| 구장 홈 대회 | 매월 셋째 주 | 각자의 홈 구장 | 홈 구장 설정자 자동 참가 | 그로스 | 홈 구장 리더보드 월간 1위 |
| 시즌 챔피언십 | 분기 1회, 4주 | 시즌 신규 S등급 구장 | 예선(1주, 전원) → 본선(2주, 상위 256명) → 결선(1주, 상위 16명, 실시간 크루 게임 형식) | 그로스 | 시즌 트로피(캐릭터 전시), 실물 상품(파크골프 공·클럽 세트) |
| 모임 대항전 | 분기 1회 | 운영 선정 2곳 | 모임 단위 참가, 상위 4명 합산 | 모임 합산 | 모임 명예의 전당, 모임 전용 깃발 아이템 |
| 스폰서 대회 | 비정기 | 협찬사·지자체 지정 구장 | 이벤트 | 대회별 | 실물 경품, 지자체 홍보 |

**12.2 참가·채점 규칙**

| 규칙 | 내용 |
| --- | --- |
| 난이도 고정 | 대회 라운드는 '일반' 난이도, 바람·날씨 고정값(대회 생성 시 시드 확정)으로 전원 동일 조건 |
| 시도 횟수 | 대회별 제한, 모든 시도는 전적에 남고 베스트만 순위 반영 |
| 중도 포기 | 완주하지 않은 시도는 순위에서 제외, 시도 횟수는 차감 |
| 동점 처리 | ① 후반 9홀(18홀 대회) ② 버디 이상 개수 ③ 먼저 제출한 순 |
| 부정행위 | 샷 입력값과 결과를 서버가 재검증. 물리 불일치 시 해당 시도 무효, 3회 누적 시 대회 참가 30일 정지 |
| 결과 확정 | 마감 후 1시간 검증 유예, 이후 순위·보상 자동 지급, 푸시 알림 |

**12.3 대회 생성 템플릿 (운영 도구)**

```
대회 템플릿
  이름 규칙      : {주차} 주간 오픈 · {구장명}
  주기           : cron (예: 매주 월 00:00 KST)
  기간           : 7일
  구장 선정 규칙 : 등급 ≥ A, 최근 8주 미사용, 권역 순환
  홀 수·난이도   : 18홀 · 일반 · 바람 시드 고정
  시도 횟수      : 3
  순위 기준      : 그로스 / 네트
  보상 테이블    : 1~3위 / 상위 10% / 참가 전원
  공지 발송      : 시작 24시간 전 푸시, 마감 6시간 전 푸시
```

**12.4 대회 화면**

## 13. 상점·판매 시스템

상점은 **인게임 아이템 상점**과 **실물 파크골프 용품 커머스** 두 개의 탭으로 나뉜다. 실물 판매는 게임 밖 결제(PG)로 처리해 앱 마켓 수수료 30%를 피하고, 인게임 아이템은 인앱 결제로 처리한다. 두 쪽은 '구매하면 게임 안에도 같은 모델이 생긴다'는 연결로 묶는다.

**13.1 재화 구조**

| 재화 | 획득 | 사용 | 비고 |
| --- | --- | --- | --- |
| 코인(무료 재화) | 라운드 완주(9홀 50), 파 이내 보너스(+30), 일일 챌린지(100), 대회 참가(200), 스탬프(300) | 일반 의상·신발·공 스킨, 염색, 승급 재료 | 일 획득 상한 1,000 |
| 젬(유료 재화) | 인앱 결제(₩1,200/100젬 ~ ₩99,000/10,000젬), 시즌패스 보상 | 한정 의상·세트, 시즌패스, 승급 가속, 구장 팩 선구매 | 환불·소멸 정책 명시 |
| 승급 토큰 | 같은 아이템 중복 획득, 세트 완성, 대회 입상 | 14절 업그레이드 전용 | 거래 불가 |
| 실물 포인트 | 실물 구매액의 3% 적립 | 실물 구매 시 현금처럼 사용 | 인게임 재화와 교환 불가 |

**13.2 인게임 아이템 상점**

| 카테고리 | 품목 예시 | 가격대 | 입수 경로 |
| --- | --- | --- | --- |
| 의상(상의·하의·모자·장갑) | 협회 공식 유니폼 스타일, 바람막이, 조끼, 챙모자, 버킷햇 | 일반 500~2,000코인 / 한정 300~800젬 | 상점, 시즌패스, 대회 보상 |
| 신발 | 파크골프화(스파이크리스), 스니커즈, 겨울 방한화 | 800~3,000코인 / 한정 500젬 | 상점, 스탬프 보상 |
| 외모 | 헤어 12종, 안경·선글라스, 피부톤, 체형은 무료 | 헤어 300코인, 안경 200코인 | 상점 |
| 클럽 스킨 | 샤프트 색상, 헤드 디자인, 그립 패턴 | 1,000~2,500코인 / 브랜드 콜라보 600젬 | 상점, 실물 구매 연동 |
| 공 스킨 | 색상 16종, 마커 패턴, 야광 | 200~800코인 | 상점, 실물 구매 연동 |
| 이모티콘·칭호 | 응원 이모티콘 세트, 프로필 칭호 | 300~1,000코인 | 상점, 업적 |
| 구장 팩 | 신규 S등급 구장 선구매 | 300젬 또는 시즌패스 포함 | 상점 |
| 시즌패스 | 3개월, 50레벨, 무료 트랙 + 유료 트랙 | 1,500젬(약 ₩19,000) | 상점 |
| 광고 제거 | 영구 | 3,000젬 | 상점 |

- 확률형 뽑기는 넣지 않는다. 시니어 타깃의 신뢰와 규제 리스크를 피하고, 모든 아이템은 가격이 보이는 직접 구매 또는 플레이 보상으로만 얻는다.
- 한정 아이템은 종료일과 재판매 여부를 명시한다.

**13.3 실물 파크골프 용품 커머스**

| 항목 | 내용 |
| --- | --- |
| 판매 품목 | 파크골프 공(협회 공인구, 색상별), 클럽(브랜드 입점: 국내 주요 제조사 3~5개사 제휴), 장갑·모자·가방 등 소품 |
| 판매 방식 | 자체 운영 또는 제휴 쇼핑몰 연동(위탁). 1차는 위탁 연동으로 재고 부담 없이 시작 |
| 결제 | 앱 내 웹뷰로 PG 결제(카드·간편결제). 배송지·주문 관리는 커머스 백엔드 |
| 게임 연동 | 실물 클럽·공 구매 시 같은 디자인의 인게임 스킨 자동 지급 + 승급 토큰 1개 |
| 인게임 노출 | 상점 실물 탭, 구장 상세 페이지 하단 '이 구장 근처 용품점', 라운드 결과 화면에 '오늘 쓴 공과 같은 실물 공' 배너 1회 |
| 피팅 가이드 | 키·연령·스윙 성향(게임 통계 기반) → 추천 클럽 길이·무게 가이드. 추천은 참고용이며 판매 강요 금지 |
| 모임 공동구매 | 모임장이 공동구매를 열면 멤버가 모아서 주문, 수량 할인 |
| 리뷰 | 실물 구매자만 리뷰 작성, 게임 전적과 연결(핸디캡 n인 사용자 리뷰) |

**13.4 결제·운영 원칙**

- 60대 이상 사용자를 고려해 결제 전 확인 화면을 2단계(금액 재확인 → 비밀번호/생체)로 두고, 월 인앱 결제 한도(기본 ₩100,000, 설정에서 변경)를 둔다.
- 모든 가격은 원화 표기, 재화 환산 표기(젬 → 원)를 병기한다.
- 실물 커머스는 전자상거래법상 통신판매업 신고·청약철회 규정을 따르고, 위탁 판매 시 판매자 정보를 명시한다.

## 14. 캐릭터·아이템 수집 및 업그레이드

캐릭터는 **외모·의상·신발·장비 4계열의 슬롯**으로 구성되고, 아이템은 등급이 있는 수집품이다. 같은 아이템을 모으거나 세트를 완성하면 **승급(업그레이드)**해 외형이 화려해지고 칭호·효과가 열린다. 승급은 샷 결과(비거리·정확도)에 절대 영향을 주지 않는다. 공정성이 깨지면 대회와 기록의 의미가 사라지기 때문이다.

**14.1 캐릭터 슬롯 구조**

| 계열 | 슬롯 | 선택지 | 변경 비용 |
| --- | --- | --- | --- |
| 외모 | 성별·연령대 | 남/여 × 30대·50대·60대·70대 체형 프리셋 | 무료, 언제든 변경 |
| 외모 | 피부톤 | 6단계 | 무료 |
| 외모 | 헤어 | 12종 × 색상 8종 | 스타일 300코인, 색상 100코인 |
| 외모 | 얼굴 | 눈·눈썹·입 각 6종, 주름·안경 옵션 | 무료 |
| 의상 | 모자 | 챙모자·버킷햇·비니·썬캡 | 아이템 |
| 의상 | 상의 | 티셔츠·폴로·바람막이·조끼·패딩 | 아이템 |
| 의상 | 하의 | 바지·반바지·치마바지 | 아이템 |
| 의상 | 장갑 | 좌/우/양손 | 아이템 |
| 신발 | 신발 | 파크골프화·스니커즈·방한화·샌들(여름 한정) | 아이템 |
| 장비 | 클럽 스킨 | 헤드·샤프트·그립 | 아이템 |
| 장비 | 공 스킨 | 색상·마커 | 아이템 |
| 장비 | 가방·소품 | 등 뒤 가방, 손목 거리측정기, 수건 | 아이템 |

**14.2 아이템 등급과 수집**

| 등급 | 색 | 입수 경로 | 외형 특징 | 수집 비율(총 아이템 중) |
| --- | --- | --- | --- | --- |
| 일반(C) | 회색 | 코인 상점, 라운드 보상 | 단색 기본형 | 50% |
| 고급(B) | 초록 | 코인 상점 상위, 스탬프 보상 | 패턴·로고 | 30% |
| 희귀(A) | 파랑 | 젬 상점, 대회 상위 10%, 권역 완주 | 질감·반사 재질 | 15% |
| 전설(S) | 금색 | 시즌 챔피언십 1~3위, 시즌패스 50레벨, 실물 콜라보 | 파티클 효과, 전용 애니메이션(세리머니) | 5% |

- 수집 도감: 전체 아이템을 계열·등급별 격자로 표시, 보유/미보유, 입수 경로 안내. 도감 달성률 25·50·75·100%마다 칭호와 젬 보상.
- 중복 획득: 이미 가진 아이템을 보상으로 다시 받으면 승급 토큰으로 자동 변환(C: 1개, B: 2개, A: 5개, S: 15개).
- 세트: 같은 테마의 모자·상의·하의·신발 4종(예: '삼락 가을 세트'). 4종 착용 시 세트 효과(캐릭터 주변 낙엽 이펙트 등) + 세트 칭호.

**14.3 승급(업그레이드) 시스템**

아이템이 아니라 **캐릭터 자체가 승급**한다. 수집 활동이 일정 기준에 도달하면 캐릭터 레벨이 오르고, 레벨별로 외형 효과·칭호·상점 할인이 열린다.

| 레벨 | 명칭 | 승급 조건(모두 충족) | 열리는 것 |
| --- | --- | --- | --- |
| 1 | 입문 | 계정 생성 | 기본 의상 2벌 |
| 2 | 동네 플레이어 | 라운드 10회 완주, 아이템 10종 보유, 승급 토큰 5 | 헤어 색상 전체, 프로필 테두리 |
| 3 | 구장 단골 | 라운드 50회, 구장 5곳 스탬프, 아이템 30종, 토큰 20 | 세트 효과 활성화, 상점 5% 할인 |
| 4 | 권역 순례자 | 라운드 150회, 권역 1곳 완주, A등급 이상 5종, 토큰 50 | 세리머니 애니메이션 선택, 캐릭터 배경 꾸미기 |
| 5 | 전국 여행자 | 라운드 400회, 구장 50곳, 세트 3개 완성, 토큰 120 | 전용 등장 연출, 상점 10% 할인, 모임 깃발 커스텀 |
| 6 | 명예의 전당 | 라운드 1,000회, 구장 100곳, S등급 1종, 대회 입상 3회, 토큰 300 | 금색 네임플레이트, 구장 상세 페이지 '명예 플레이어' 노출 |

- 승급은 조건 충족 시 '승급하기' 버튼이 켜지고, 승급 연출(캐릭터가 클럽을 들어 올리는 10초 애니메이션)을 재생한다. 자동으로 오르지 않아 성취의 순간을 사용자가 직접 누른다.
- 승급 가속: 젬으로 승급 토큰을 살 수는 있으나(10젬/1토큰), 라운드 수·구장 수 조건은 구매로 대체할 수 없다. 돈으로는 시간을 사지 못하게 한다.
- 개별 아이템 강화(+1, +2)는 두지 않는다. 시니어 사용자에게 강화 실패·소멸 개념은 불필요한 스트레스다.

**14.4 인벤토리·착용 UI**

- 옷장 화면: 왼쪽에 캐릭터 전신(회전 가능), 오른쪽에 계열 탭(외모·모자·상의·하의·장갑·신발·장비). 아이템 탭하면 즉시 미리보기, '저장'으로 확정.
- 코디 저장 슬롯 5개(봄·여름·가을·겨울·대회용). 구장 계절에 맞춰 자동 추천.
- 캐릭터는 라운딩 중 3인칭 샷 장면·결과 화면·스코어카드 이미지·대회 리더보드 아이콘에 노출된다. 공·클럽 스킨은 샷 카메라에서 확대되어 보이므로 가장 자주 보는 아이템이다.
- 친구 캐릭터 구경: 친구 프로필에서 착용 아이템을 눌러 상점으로 바로 이동(입수 경로 표시).

## 15. 리스크 및 검토 사항

가장 큰 리스크는 기술이 아니라 **구장 데이터 확보 권한과 제작 물량**이다. 프리프로덕션 단계에서 협회·지자체와의 데이터 사용 협의를 먼저 끝내야 한다.

| 리스크 | 영향 | 대응 |
| --- | --- | --- |
| 구장 명칭·배치도 사용 권리 | 지자체 소유 시설이라 상업적 이용 시 허가 필요. 무단 재현 시 분쟁 | 지자체 홍보 효과를 내세운 무상 사용 협약 템플릿 마련, 거부 구장은 B등급 익명 레이아웃으로 대체 |
| 항공사진·DEM 라이선스 | 국토지리정보원 공개 데이터는 비상업 조건이 붙는 경우 있음 | 개발 착수 시 데이터별 이용 조건 확인, 필요 시 유료 라이선스 또는 자체 드론 촬영 |
